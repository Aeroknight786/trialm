# P1a handoff

Implemented on branch `p1a`, using only the standard library. No commits or pushes were made. Apply `/tmp/claude-501/p0b/p1a-1.patch` through `p1a-4.patch` in numerical order; each has a one-line description in the corresponding `.txt` file. The patches are incremental, not cumulative.

`cmd/trialm/main.go` is 13 physical lines. `internal/core` owns detection, recommendation/file/runtime selection, trial evaluation, GGUF loading and stand-ins, and exposes Session, Event and Sink. Compatibility probes moved to `internal/verify`. Existing plain cards moved to `internal/ui`; uncertain numeric formatting moved to `internal/figure`. Calibration commands and terminal handling moved to `internal/calibrationcli` and `internal/terminal` to keep package sizes within the plan's limits.

`internal/cli` supplies home, find, try, setup, launch, key, update, and the compatibility aliases. `find` accepts a model query, saves numbered recipes in `last.json`, and accepts requirement flags over `prefs.json`. Saved calibration preferences survive preference writes. Setup hashes the complete plan, accepts bare `--yes`, refuses a changed `--yes=<plan_id>` with exit 4, and describes v0.5 execution without running setup commands. Launch is the requested v0.5 stub. Window launch and built-in chat remain P1b work; opt-in YaRN remains P3 work. Explicitly requesting an unavailable flow reports the relevant flag or release.

The new commands emit versioned NDJSON with Figure payload numbers and `next` on every result. Legacy JSON aliases retain their characterization format for one release. Human trial output goes to stderr in JSON mode. Mode and exit tests cover success, errors, usage, needs-user, not-ready and interruption; a real child process test checks Ctrl-C during a foreground trial exits 130. Plain piped output contains no escape bytes.

`internal/store` owns 0600 credentials and preference/listing state. `internal/openrouter` implements S256 PKCE, a random loopback callback port and unpredictable callback path, code exchange, credits, and endpoint discovery. Key precedence is OPENROUTER_API_KEY, credentials, then the old config key; env keys are not persisted. Browser, headless code, masked paste, removal, credits and error redaction are tested against httptest. Tests inject a browser opener and secret reader; they open no real browser and make no real OpenRouter API calls.

`internal/trial` rejects logging/unknown policies, checks context/tool support, ranks declared precision/uptime/price, and pins one tag with `data_collection: deny`, fallbacks disabled and required parameters. `--zdr` additionally requires ZDR. Public endpoint records can omit privacy fields: those are joined by exact model/tag/precision to `/endpoints/zdr`, requiring explicit `safety_retention: false`; an explicit logging policy is never overwritten. The fixture tests cover unknown policy, contradictory policy, logging, safety retention, wrong model/precision, missing price, context and tool gates. If policy cannot be established, the trial stops rather than choosing a logging endpoint.

The default $2 client cap serializes cloud admission, reserves a conservative prompt allowance, clamps affordable completion tokens, and accounts response usage at the pinned endpoint's prices, including cache-read and per-request charges. It stops at the cap with `triaLM trial budget reached ($2.00): trialm try --budget 5 to continue`. Missing usage stops subsequent admission. As specified in the plan, this is a client-side guard: provider-reported usage/prices remain the authority; provider billing or price drift requires the owner's live check. Custom upstreams used by the existing harness runner have no OpenRouter price metadata and explicitly show unknown spend/privacy rather than a fabricated bill.

Trials support p50/p90 pacing, declared-precision fidelity labels, cloud-bound logs/counts, a one-time privacy notice, playground working directories, and a plain/JSON summary: requests, local/cloud time, reading/writing/load/between-turn time, first/typical/slowest turn and cause, cache reuse, loads, context peak/overflows and spend. Between-turn time is labelled tools/user because tool-only time is not observable here. The existing `Endpoints on ...` and harness connection snippets remain compatible with `tools/harness-e2e`; the runner was unchanged and its tests passed.

`internal/selfupdate` reads the latest Aeroknight786/trialm GitHub release, verifies the archive against that release's checksums.txt, extracts only the expected binary, and replaces a caller-supplied executable atomically (with Windows rollback handling). Tar/zip and checksum failures are tested with temporary targets and httptest. Home reads a cached notice immediately and starts a detached check at most daily, with an exclusive cross-process claim. No installed binary was replaced in tests.

The source budget counts non-test Go lines containing tokens, excluding comments and blank lines, across cmd and internal. P1a has no separate global ceiling in §9, so the test adopts the stricter v0.4 ceiling now: 26,000 total; cli+ui 5,500; 2,500 per package; hw 2,600 until P3; API wire packages together 4,400; cmd/trialm 30 physical lines; stripped binary 14,000,000 bytes. The UI lint rejects raw float formats with speed/time units. Final measurements: 22,906/26,000 source lines; cli+ui 2,967/5,500; cmd/trialm 13/30 physical lines; stripped macOS arm64 binary 9,380,770/14,000,000 bytes. The same trimmed/stripped baseline built from HEAD is 8,976,850 bytes, a 403,920-byte increase. The increase above 300 KB is justified by the required PKCE/endpoint/privacy/budget code and the verified tar/zip updater; no dependency or catalog expansion was added.

Validation completed: `gofmt -l .` empty; `go vet ./...`; `go test -race ./...` including goldens; Linux and Windows cross-builds. Goldens were regenerated only at the end with `go test ./cmd/... -run TestGolden -update`. `TestFindLegacyEquivalence` compares every recommendation field against both legacy recommendation golden variants on all six fixtures after removing Figure wrappers.

New tests live in cmd/trialm/p1a_test.go and internal/{budgets,core,figure,openrouter,store,trial,ui,selfupdate}, plus key/mode/interruption tests in internal/cli. Existing tests moved with the extracted code. Files outside those new/extracted areas: internal/server/server.go (summary callback and cloud-bound log label), cmd/trialm/golden_test.go (explicit scratch TRIALM_HOME), these four golden lines, and docs/STATUS.md.

No model weights were downloaded, no sudo was used, and no real harness configuration or owner state was changed. Those live checks remain open questions, not claims of support established by fake tests.
